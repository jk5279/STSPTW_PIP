# Trillium / DRAC cluster scripts

Shell and Slurm helpers under `trillium_scripts/` for environment setup, S-PIP training, evaluation, and job submission. Paths below are relative to the repository root unless noted.

| File | What it does | Explicit non-default flags set | Calls |
|------|----------------|-------------------------------|--------|
| `run_train_spip_n10.sh` | S-PIP training for `TSPTW_SPIP`, n=10, 10k epochs × 10k episodes; optionally generates validation `.pkl`; copies checkpoints to `src/saved_models/…`. | `HARDNESS` (default `hard`); `VAL_SEED` (default `2027`); `TRAIN_BATCH_SIZE` (default `256`); `STOCHASTIC`/`--stochastic` → `--spip_stochastic_transition True` and alternate log dirs; `PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION=python`; `PYTHONPATH` includes repo root. Training uses `--generate_PI_mask`, fixed epochs/episodes/intervals, `--log_dir`, `--val_dataset`. | `python generate_data.py` (if val file missing), `python train.py` (cwd `src/`) |
| `run_train_spip.sh` | Generic training for `TSPTW_SPIP` / `STSPTW` / `STSPTW_v2` via env vars; optional val data generation; optional resume (`RESUME_CHECKPOINT`, `RESUME_PATH`, `AUTO_RESUME`, `NO_OPT_SOL`); checkpoint copy to `src/saved_models/…`. | Requires `PROBLEM_SIZE`; `PROBLEM` (default `TSPTW_SPIP`), `HARDNESS`, `TRAIN_BATCH_SIZE` (default `256`); problem-specific: `STOCHASTIC`, `DELAY_SCALE`, `NOISE_TYPE`, `CV`, `REVEAL_DELAY`; `--model_type POMO_STAR_PIP`; `PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION=python`. | `python generate_data.py` (if needed), `python train.py` (cwd `src/`) |
| `setup_venv.sh` | Loads cluster modules (`StdEnv/2023`, `python/3.11.5`, CUDA), creates/activates venv (`VENV_DIR` or `venv/`), `pip install` PyTorch, scipy, matplotlib, tqdm, etc. | `VENV_DIR` optional override. | *(no `src/*.py` entry point; module/pip only)* |
| `run_spip_n10_test.sh` | Runs `test.py` for S-PIP n=10 for easy/medium/hard if checkpoints exist under `src/results/spip_tsptw10_100M/…`. | `--test_batch_size 512`, `--test_episodes 10000`, `--generate_PI_mask`, `--fsb_dist_only True`; `PYTHONPATH` repo root. | `python test.py` (cwd `src/`) |
| `submit_spip_eval_parallel.sh` | Submits one Slurm job that runs parallel eval on a full node. | `sbatch` flags: `--account=def-cglee`, `--partition=compute_full_node`, `--gpus-per-node=4`, `--cpus-per-task` (default 96), `--time` (default `01:00:00`); CLI `--sizes`, `--hardness`, `--time`, `--cpus`; passes `SIZES`/`HARDNESS` via `--export`. | `sbatch … run_spip_eval_parallel.slurm` |
| `submit_spip_sweep_cglee.sh` | Submits n=50 and n=100 S-PIP jobs (det and/or stoch) via `sbatch`. | Optional `--det-only` or `--stoch-only`. | `sbatch` on each listed `run_spip_*_cglee.slurm` |
| `run_spip_eval_parallel.slurm` | Inside one allocation, runs `run_test_spip.py` for each (size, hardness) pair in waves per GPU; writes CSV under `results/`, logs under `src/logs/slurm/`. | `#SBATCH` resources; `SIZES`/`HARDNESS` env strings; `OMP_NUM_THREADS=1` etc.; `PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION=python`; `cd` to `src/`. | `python ../scripts/test/run_test_spip.py` (with `--sizes`, `--hardness`, `--results_csv`) |
| `run_spip_eval_single.slurm` | Single-GPU eval for one (`SIZE`, `HARDNESS`); writes one CSV. | `#SBATCH` 1 GPU, 8 CPUs, 30 min, `rrg-cglee`; requires `SIZE` and `HARDNESS` env. | `python ../scripts/test/run_test_spip.py` |
| `run_spip_n10.slurm` | Slurm wrapper: modules, venv, then runs n=10 training script. | `#SBATCH` 24 h, 1 GPU, 24 CPUs; placeholder `YOUR_ACCOUNT_HERE`; `STOCHASTIC` env (default `0`). | `bash trillium_scripts/run_train_spip_n10.sh` |
| `run_spip_n10_cglee.slurm` | Same as other n=10 cglee jobs but `#SBATCH --time=5:00:00`; default `HARDNESS=hard`, `TRAIN_BATCH_SIZE=256`. | `HARDNESS`, `STOCHASTIC`, `TRAIN_BATCH_SIZE` exports. | `bash …/run_train_spip_n10.sh` |
| `run_spip_n10_easy_cglee.slurm` | n=10 S-PIP training, hardness easy (default). | `HARDNESS` default `easy`, `STOCHASTIC` default `0`. | `bash …/run_train_spip_n10.sh` |
| `run_spip_n10_medium_cglee.slurm` | n=10 S-PIP training, hardness medium (default). | `HARDNESS` default `medium`, `STOCHASTIC` default `0`. | `bash …/run_train_spip_n10.sh` |
| `run_spip_n50_easy_cglee.slurm` | n=50, easy, deterministic S-PIP via `run_train_spip.sh`. | `PROBLEM_SIZE=50`, `HARDNESS=easy`, `STOCHASTIC=0`. | `bash …/run_train_spip.sh` |
| `run_spip_n50_easy_stoch_cglee.slurm` | n=50, easy, stochastic transitions. | `PROBLEM_SIZE=50`, `HARDNESS=easy`, `STOCHASTIC=1`. | `bash …/run_train_spip.sh` |
| `run_spip_n50_medium_cglee.slurm` | n=50, medium, deterministic. | `PROBLEM_SIZE=50`, `HARDNESS=medium`, `STOCHASTIC=0`. | `bash …/run_train_spip.sh` |
| `run_spip_n50_medium_stoch_cglee.slurm` | n=50, medium, stochastic. | `PROBLEM_SIZE=50`, `HARDNESS=medium`, `STOCHASTIC=1`. | `bash …/run_train_spip.sh` |
| `run_spip_n50_hard_cglee.slurm` | n=50, hard, deterministic. | `PROBLEM_SIZE=50`, `HARDNESS=hard`, `STOCHASTIC=0`. | `bash …/run_train_spip.sh` |
| `run_spip_n50_hard_stoch_cglee.slurm` | n=50, hard, stochastic. | `PROBLEM_SIZE=50`, `HARDNESS=hard`, `STOCHASTIC=1`. | `bash …/run_train_spip.sh` |
| `run_spip_n100_easy_cglee.slurm` | n=100, easy, deterministic. | `PROBLEM_SIZE=100`, `HARDNESS=easy`, `STOCHASTIC=0`. | `bash …/run_train_spip.sh` |
| `run_spip_n100_easy_stoch_cglee.slurm` | n=100, easy, stochastic. | `PROBLEM_SIZE=100`, `HARDNESS=easy`, `STOCHASTIC=1`. | `bash …/run_train_spip.sh` |
| `run_spip_n100_medium_cglee.slurm` | n=100, medium, deterministic. | `PROBLEM_SIZE=100`, `HARDNESS=medium`, `STOCHASTIC=0`. | `bash …/run_train_spip.sh` |
| `run_spip_n100_medium_stoch_cglee.slurm` | n=100, medium, stochastic. | `PROBLEM_SIZE=100`, `HARDNESS=medium`, `STOCHASTIC=1`. | `bash …/run_train_spip.sh` |
| `run_spip_n100_hard_cglee.slurm` | n=100, hard, deterministic. | `PROBLEM_SIZE=100`, `HARDNESS=hard`, `STOCHASTIC=0`. | `bash …/run_train_spip.sh` |
| `run_spip_n100_hard_stoch_cglee.slurm` | n=100, hard, stochastic. | `PROBLEM_SIZE=100`, `HARDNESS=hard`, `STOCHASTIC=1`. | `bash …/run_train_spip.sh` |
| `run_stsptw_v2_n10_cglee.slurm` | STSPTW v2 training n=10: sets `PROBLEM=STSPTW_v2`, noise and batch env vars, then runs generic training script. | `PROBLEM_SIZE=10`, `HARDNESS` (default `hard`), `NOISE_TYPE`, `CV`, `REVEAL_DELAY` (default `1`), `TRAIN_BATCH_SIZE` (default `1024`). | `bash …/run_train_spip.sh` |
